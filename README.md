# Week 1 Assessment

## Setup

1. Create an environment with `python -m venv .venv`.
2. Activate it with `.venv\Scripts\Activate.ps1` on PowerShell.
3. Install packages with `pip install -r requirements.txt`.
4. Open `notebooks/employee_analysis.ipynb` in Jupyter.
5. Run `python src/employee_analysis.py` after opening it in IPython.

## Findings

- The dataset contains 8 employees in 4 departments.

- Finance has the highest individual salary at 90,000.
